# COVID-19 Data Exploration using SQL & Tableau

## Project Overview

This project focuses on exploring and analyzing global COVID-19 data using **MySQL** and **Tableau**. The analysis includes infection trends, death percentages, vaccination progress, and population impact across different countries and continents.

The goal of this project was to strengthen skills in:

* SQL data analysis
* Data cleaning
* Window functions
* Joins & CTEs
* Data visualization
* Dashboard creation
